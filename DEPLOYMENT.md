# Virendra Yadav Portfolio

In GitHub repository **Settings → Pages**, select **GitHub Actions** as the source.
Push to `main` to build and publish using `.github/workflows/pages.yml`.

Site address: https://veerworkholics.github.io/virendra-yadav-portfolio/

The workflow determines the repository base path automatically. Images, resume
downloads, and navigation support that base path. The contact form opens an email
draft in the visitor's email app.

For local development, run `npm ci` and `npm run dev`.
